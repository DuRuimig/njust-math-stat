核验日期：2026-07-25。

本目录只保存本次原型可使用的公开目录事实，不将目录信息误写成课程教师履历。

## 范围

- 源课程教师：`prototype/data.js` 的开课记录，去重后 61 人。
- 学院师资匹配范围：其中开课单位为“数学与统计学院”的 43 人。
- 学院师资来源：[数学与统计学院师资名录](https://math.njust.edu.cn/15518/list.htm)。只读取名录页中的姓名、系别分类和其给出的目录链接；未进入任何个人主页。
- 研究生导师来源：[研究生院导师目录](https://gsmis.njust.edu.cn/open/DsDir_View.aspx?yxsh=130) 的 `0701 数学` 行。仅记录页面明确标出的“博导”或“硕导”，不把它推断为本科任课、职称、研究方向或当前在岗状态。

- 1 人：成灵妍列在概率统计系，但其目录链接回到师资名录页；`teacher-directory.json` 将个人链接保留为空。

- 18 人：其课程记录的开课单位是计算机科学与工程学院或经济管理学院，未拿去做数统学院师资匹配，也不据此判断其院系归属。
- `0701 数学` 行内：14 位被明确标为博士生导师、17 位被明确标为硕士生导师、12 位未出现在该行。最后一类只表示该行未列出，不表示其没有任何导师资格。

## 使用边界

`teacher-directory.json` 可作为后续原型的“学院目录链接/系别”和“研究生导师资格目录”候选静态数据。接入 UI 前仍应保持字段标签明确：

- `department`：学院师资名录的系别分类。
- `academyDirectoryLink`：名录页给出的目录链接，未核验其详情内容。
- `graduateAdvisor0701`：研究生导师目录中 `0701 数学` 的资格标记，不是本科课程的师资证明。
- 职称和研究方向：本次两张目录页均未提供，继续留空。
