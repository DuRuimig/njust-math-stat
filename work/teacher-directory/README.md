# 教师目录匹配快照

核验日期：2026-07-28。

本目录只保存本次原型可使用的公开目录事实，不将目录信息误写成课程教师履历。

## 范围

- 源课程教师：`prototype/data.js` 的开课记录，去重后 61 人。
- 学院师资匹配范围：学院官网当前名录的 92 位教师，以及课程记录中的 3 位历史任课教师。
- 学院师资来源：[数学与统计学院师资名录](https://math.njust.edu.cn/15518/list.htm)。记录其明确给出的系别分类和个人页链接；随后逐页读取个人页的“现任职称”非空字段。
- 研究生导师来源：[研究生院导师目录](https://gsmis.njust.edu.cn/open/DsDir_View.aspx?yxsh=130)。汇总页面中明确标出的“博导”和“硕导”，覆盖全部学科行；不把未列明推断为没有导师资格。

## 结果

- 92 人：当前学院官网师资名录，分布为数学系 37 人、计算科学系 25 人、概率统计系 14 人、大学数学基础教学中心 16 人；其中 91 人有个人页链接，成灵妍的目录链接回到师资名录页。
- 3 人：丁利、刘东生、袁亮亮未在当前学院师资名录中出现，保持系别和链接为空。
- 52 人：个人页“现任职称”字段非空；其余个人页为空时保留空值，不使用网页外推断补写。
- 研究生导师目录中未列明的教师被显式标为“未列明（不作资格否定）”。

## 使用边界

`teacher-directory.json` 可作为后续原型的“学院目录链接/系别、职称和研究生导师资格”候选静态数据。接入 UI 时保持字段标签明确：

- `department`：学院师资名录的系别分类。
- `title`：学院个人页“现任职称”的非空原值；空值只表示该页面未填写。
- `graduateAdvisorRoles`：研究生院导师目录中明确出现的角色数组；空数组只表示目录未列明，不是资格否定。
- `academyDirectoryLink`：师资名录给出的个人页链接。
